# 売上データと市場情報から成長戦略を決める｜CXO-11

| 項目 | 内容 |
|---|---|
| **目的** | 「売上は伸びている」で止まっている会話を、投資するカテゴリ・見直すカテゴリ・次の出店先まで進める |
| **所要** | 約 25 分（目安） |
| **利用** | Copilot in Excel ／ Web 検索を利用できる Copilot エクスペリエンス（Microsoft 365 Copilot Chat など） |
| **入力** | [`TrendStyleJapan-SalesData.xlsx`](../assets/CXO-11/TrendStyleJapan-SalesData.xlsx)（架空企業のサンプル ブック） |
| **成果** | 収益上の課題 3 点、投資判断用のバブルチャート 2 枚、新規出店候補 3 件、役員会向けサマリー 1 枚 |

> **実施条件**：Excel で Microsoft 365 Copilot が使える場合にハンズオンで実施します。
> ブックは OneDrive または SharePoint に保存し、自動保存を有効にしてください。
> そうでない場合は、ファシリテーターのデモを見ながら進めてください。

> **Web 検索について**：ステップ 3 と ステップ 7 では Web 上の公開情報を使います。Excel 内の Copilot から Web 検索を利用できない環境では、Microsoft 365 Copilot Chat など Web 検索を利用できる Copilot で同じ調査を行い、結果を Excel の新しいシート（例：`Web市場トレンド`）へ貼り付けてから先へ進んでください。

---

## シナリオ

あなたは、アパレルメーカー兼小売企業 **TrendStyle Japan**（架空の企業です）の経営企画部長です。

社長から、こう言われています。

> 売上は伸びているように見えるが、このまま同じ商品と地域に投資してよいのか。
> 社内の販売実績だけでなく、いまの市場トレンドも踏まえて、来年度の成長戦略を提案してほしい。

役員会までに決めるのは 3 つです。**どのカテゴリへ投資するか、どのカテゴリを見直すか、どの地域を強化し次にどこへ出店するか**。

手元にあるのは 2,160 行の販売明細です。合計を眺めても答えは出ません。合計が伸びていても、**その伸びを牽引している商品がいちばん儲かっていない**ということが普通に起こります。

この体験では、数字を「読む」のではなく「**質問する**」ことをします。順番は 6 手です。① 全体をつかむ → ② 売上と利益のズレを探す → ③ 外の市場を調べる → ④ 投資候補を選ぶ → ⑤ 判断用のチャートにする → ⑥ 出店先を決めて 1 枚にまとめる。

> 進行役の説明例：「今日のゴールは、きれいなグラフではありません。**このグラフなら投資先を議論できる**、と言える状態です。Copilot が出した数字は、必ず元表で 1 つ検算してください。」

---

## TRY — 手順

### 準備

1. [`TrendStyleJapan-SalesData.xlsx`](../assets/CXO-11/TrendStyleJapan-SalesData.xlsx) を OneDrive または SharePoint に保存し、Excel で開く
2. **「はじめに」** シートを開き、次の 7 シートがあることを確認する

   | シート | 内容 |
   |---|---|
   | はじめに | ファイルの説明、データの前提、質問例 |
   | 売上データ | 売上明細 2,160 行（2024 年 1 月〜2025 年 12 月／15 店舗 × 6 カテゴリ × 24 か月） |
   | カテゴリ別集計 | 商品カテゴリ別の売上・成長率・粗利率（数式で自動集計） |
   | 地域別集計 | 地域別・店舗タイプ別の売上・成長率・粗利率（数式で自動集計） |
   | 店舗マスタ | 15 店舗の立地、売場面積、インバウンド売上比率 |
   | 商品カテゴリマスタ | 単価、標準粗利率、ターゲット層、業界市場成長率 |
   | MarketData | 都道府県別の市場規模、成長率、インバウンド指数、出店状況（未出店県を含む） |

3. Copilot アイコンを選び、Copilot ウィンドウが開くのを待つ

### ステップ 1 — まず会社全体をつかむ

4. 次のプロンプトを送信する

```text
このワークブックに含まれるデータを確認し、
TrendStyle Japanの事業と売上構造を経営企画部長向けに要約してください。

次の観点を含めてください。
・主力の商品カテゴリ
・主要な地域
・店舗タイプ別の特徴
・2024年から2025年にかけての売上傾向
・利益構造
・経営上、最初に確認すべき点

金額、成長率、粗利率などの根拠も示してください。
```

5. 全社の売上傾向、売上規模の大きいカテゴリと地域、店舗タイプによる収益性の違いを確認する

> ここでは、売上上位をそのまま「投資対象」と判断しません。**売れている商品と、儲かる商品は同じとは限らない**という問いを残して次へ進みます。

### ステップ 2 — 売上と利益のズレを探す

6. 続けて次のプロンプトを送信する

```text
2024年と2025年の売上、粗利、粗利率を比較してください。

特に、
・売上成長に対して粗利が十分に増えているか
・売上規模は大きいが、粗利率が低い商品カテゴリ
・成長しているが、収益性に注意が必要な商品カテゴリ
・店舗タイプによる収益性の違い

を分析してください。

最後に、社長へ報告すべき問題を3点に整理してください。
```

7. **「カテゴリ別集計」シートに戻り、出てきた数字を 1 つだけ検算する**（売上構成比、または最大カテゴリの粗利率）

> 参加者が「え？」となるのはここです。**売上構成比も成長率も 1 位のカテゴリが、粗利率では最下位**という状態が見えます。「一番売れている商品へ投資すればよい」とは限らない、が体感される瞬間です。

### ステップ 3 — 外の市場を調べる

8. Web 検索を利用できる Copilot で次のプロンプトを送信する

```text
Web上の公開情報を調査し、
日本国内のアパレル市場について、現在注目すべきトレンドを整理してください。

特に次のカテゴリに関係する情報を調べてください。
・スポーツウェア／アスレジャー
・サステナブルファッション
・ビジネスウェア
・キッズアパレル
・インバウンド需要

各トレンドについて、
・市場が拡大、横ばい、縮小のどれに近いか
・その判断の根拠
・情報源名
・公開日
・参照URL

を表形式でまとめてください。

推測と確認済み情報を分け、
確認できない数値は作らないでください。
```

9. **出典を 1 つ開いて確かめる**。あわせて次を確認する

   - 一次情報または信頼できる調査機関か
   - 公開日が古すぎないか
   - 日本国内の市場情報か
   - 数字の定義や対象期間が社内データと整合するか
   - 推測が事実として書かれていないか

10. Excel 内で Web 検索を使えない場合は、確認できた項目を `Web市場トレンド` シートとしてブックへ貼り付ける

### ステップ 4 — 社内データと市場情報を突き合わせて投資候補を選ぶ

11. 続けて次のプロンプトを送信する

```text
これまで確認した社内販売実績と、
Webで調査した日本国内のアパレル市場トレンドを組み合わせて、
来年度に投資すべき商品カテゴリを3つ提案してください。

評価軸は次の5つです。
・現在の売上規模
・2025年の前年比売上成長率
・粗利率
・業界市場の成長性
・実行上のリスク

各カテゴリを5段階で評価し、
「拡大投資」
「収益改善を条件に投資」
「維持」
「縮小検討」
のいずれかに分類してください。

社内データからの根拠と、Web情報からの根拠を分けて示してください。
```

12. 分類の理由を読み、**社内データだけでは出てこなかった判断材料**がどれかを確認する

### ステップ 5 — 投資判断に使えるバブルチャートを作る

13. **「カテゴリ別集計」** シートを開く
14. 次のプロンプトを送信する

```text
「カテゴリ別集計」シートのデータを使って、
商品カテゴリ別のバブルチャートを作成してください。

・横軸：前年比成長率
・縦軸：粗利率
・バブルサイズ：売上合計
・データラベル：商品カテゴリ
・チャートタイトル：
  「商品ポートフォリオ：成長率 × 粗利率 × 売上規模」

成長率と粗利率がともに高い右上領域が分かりやすくなるようにしてください。
パーセント表示を使用し、役員会で読みやすいデザインにしてください。
```

> **うまく動かない場合**：Copilot が希望する種類のチャートを直接作成しないことがあります。その場合はカテゴリ別集計の表を選択し、Excel の ［挿入］ からバブルチャートを選んだうえで、タイトル、軸、ラベル、読み取り方の改善を Copilot に依頼してください。

15. 続けて次のプロンプトを送信し、チャートを読み解かせる

```text
このバブルチャートを経営会議の視点で分析してください。

各カテゴリを次の4象限に分類してください。
・右上：成長投資候補
・左上：高収益だが成長施策が必要
・右下：成長しているが収益改善が必要
・左下：縮小または再設計を検討

特に、
・投資額を増やす候補
・利益改善を条件に成長させる候補
・現状維持の候補
・縮小を検討する候補

を根拠付きで提案してください。
```

16. 4 象限の意味を全員で確認する

    | チャート上の位置 | 意味 | 主な判断 |
    |---|---|---|
    | 右上 | 高成長・高収益 | 成長投資候補 |
    | 左上 | 低成長・高収益 | 成長施策または選択的拡大 |
    | 右下 | 高成長・低収益 | 収益改善を条件に投資 |
    | 左下 | 低成長・低収益 | 縮小または再設計を検討 |

### ステップ 6 — 地域ポートフォリオを可視化する

17. **「地域別集計」** シートを開き、次のプロンプトを送信する

```text
「地域別集計」シートを使い、
地域別の投資優先度を判断するチャートを作成してください。

・横軸：前年比成長率
・縦軸：粗利率
・データラベル：地域
・バブルサイズ：売上合計
・タイトル：
  「地域ポートフォリオ：成長率 × 粗利率 × 売上規模」

売上規模だけでなく、
成長率と粗利率のバランスを比較できるようにしてください。
```

18. 続けて次のプロンプトを送信する

```text
このチャートを、
「既存店の追加投資」
「効率改善」
「新規出店の周辺候補」
の3つの観点で解釈してください。

売上規模だけで判断せず、
成長率と粗利率のバランスを重視してください。
```

19. 次の 3 点を議論する

    - 売上規模が最大の地域へ、さらに投資すべきか
    - 規模は小さくても、成長率の高い地域へ先行投資すべきか
    - 高収益だが成長が鈍い地域には、どのような施策が必要か

### ステップ 7 — 出店先を決め、反論させる

20. 次のプロンプトを送信する

```text
「MarketData」シートの未出店地域を対象に、
Web上の最新の公開情報も確認し、
新規出店候補を3つ提案してください。

評価軸は次のとおりです。
・市場規模
・市場成長率
・20～49歳人口比率
・インバウンド指数
・年間観光客数
・競合店舗数
・近隣の既存店実績
・Webで確認できる最近の消費、観光、商業動向

社内データとWeb情報を分けて記載し、
最終的に「優先」「要調査」「見送り」のいずれかを示してください。
出典と公開日も付けてください。
```

21. 続けて次のプロンプトを送信する

```text
最優先の出店候補について、
反対するCFOの立場から、主なリスクを5つ挙げてください。

そのうえで、出店判断前に追加確認すべきデータを示してください。
```

22. 反論を読んだうえで、**最初に調査に入る 1 件を自分で決める**

### ステップ 8 — 役員会向けの 1 枚にまとめる

23. 最後に次のプロンプトを送信する

```text
私はTrendStyle Japanの経営企画部長です。

ここまでの分析結果を使って、
来週の役員会に提出するエグゼクティブサマリーを作成してください。

構成は次のとおりです。
1. 現状認識
2. 最も重要な経営課題
3. 拡大投資する商品カテゴリ
4. 収益改善を条件に投資する商品カテゴリ
5. 既存地域への投資方針
6. 新規出店候補
7. 次の90日で行うこと

各提案には、
・社内販売データによる根拠
・Web情報による根拠
・想定リスク
・追加確認が必要な項目
を付けてください。

バブルチャートから得られた示唆も含め、
A4 1ページ程度で簡潔にまとめてください。
```

24. 出てきたサマリーを読み、**そのまま役員会に出せるか**を判断する。出せない場合、足りないのは数字か、根拠か、リスクの記述かを言葉にする

## REFLECT — 振り返り

- 合計では見えていなかった「売上と利益のズレ」は見つかったか
- 検算した数字は合っていたか。合わなかった場合、どこがずれていたか
- Web 情報を加えたことで、社内データだけの結論から変わった判断はあったか
- 出典を開いて確かめられたか。開けない情報を役員会に出せるか
- バブルチャートを見て、「投資先を議論できる」と言える状態になったか
- CFO の反論を読んで、順位が変わった出店候補はあったか

**うまく動かない場合**
ブックが OneDrive / SharePoint に保存され、自動保存が有効で、各シートのデータがテーブル形式になっていることを確認してください。

> [!CAUTION]
> Copilot が生成した数値、分析、チャート、出典は必ず確認してください。確認できない情報を推測で補わないでください。出店や投資の最終判断には、財務、市場調査、店舗開発などの専門家への確認が必要です。
