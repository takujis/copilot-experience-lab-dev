## 【Class room 10分版】売上データと市場情報から成長戦略を決める｜XLS-02

この資料は、ハンズオンを **約10分・3ステップ**で実施するための短縮版です。GitHub掲載版（フル版）は変更しません。

| 項目 | 内容 |
|---|---|
| **目的** | 売上分析から、商品投資・出店候補・役員会向け提言までを一気に進める |
| **所要** | **約10分** |
| **利用** | Copilot in Excel ／ Web検索を利用できるCopilotエクスペリエンス |
| **入力** | [TrendStyleJapan-SalesData.xlsx](https://github.com/miookawa/copilot-experience-lab/releases/download/xls-02-v1.0.0/TrendStyleJapan-SalesData.xlsx) |
| **成果** | 経営課題3点、投資判断、バブルチャート1枚、出店候補3件、役員会向けサマリー |

### 事前準備（開始前に完了）
- ブックをOneDriveまたはSharePointに保存し、自動保存を有効にする
- Excelでブックを開き、Copilotウィンドウを表示する
- 進行役は「カテゴリ別集計」と「MarketData」シートの場所を案内する

> 今日のゴールはグラフ作成ではなく、**商品と地域の投資判断を役員へ説明できる状態**にすることです。

## TRY — 3ステップ

### ステップ1 — 商品・市場・出店をまとめて判断する（約4分）

次のプロンプトを送信します。

```text
このブックの2024年・2025年実績とWeb上の日本国内アパレル市場情報を分析し、次を示してください。

1. 社長へ報告すべき収益課題3点
2. 商品カテゴリを「拡大投資／収益改善後に投資／維持／縮小検討」に分類
3. MarketDataの未出店地域から出店候補3件を選び、「優先／要調査／見送り」を判定

売上成長率、粗利率、売上規模、市場成長性、実行リスクを重視し、社内データとWeb情報の根拠を分けて簡潔に示してください。Web情報には出典と公開日を付けてください。
```

**見るポイント**
- 売上が大きいカテゴリと、利益率が高いカテゴリが一致しているか
- Web情報を加えたことで、社内データだけの判断が変わったか
- 商品投資と出店候補に、理由が付いているか

時間に余裕がある場合のみ、「カテゴリ別集計」シートで数値を1つ検算します。

### ステップ2 — 投資判断用のバブルチャートを作る（約3分）

「カテゴリ別集計」シートを開き、次のプロンプトを送信します。

```text
「カテゴリ別集計」から商品カテゴリ別のバブルチャートを作成してください。
横軸＝前年比成長率、縦軸＝粗利率、バブルサイズ＝売上合計、ラベル＝商品カテゴリ。
タイトルは「商品ポートフォリオ：成長率 × 粗利率 × 売上規模」とし、役員会で読みやすくしてください。
```

進行役が口頭で補足します。
- 右上：成長投資候補
- 右下：収益改善を条件に投資
- 左上：選択的拡大
- 左下：縮小または再設計を検討

ラベルが表示されない場合だけ、次を追加します。

```text
各バブルの商品カテゴリが分かるよう、ラベルまたは凡例を追加してください。
```

### ステップ3 — 役員会向け1ページにまとめる（約3分）

次のプロンプトを送信します。

```text
ここまでの分析とチャートを基に、役員会向けのエグゼクティブサマリーをA4 1ページ程度で作成してください。
「現状と課題／商品投資方針／出店候補／主要リスク／次の90日の行動」の順に、社内データとWeb情報の根拠を分けて簡潔にまとめてください。
```

生成結果では、次の5点だけを確認します。
- 収益課題
- 拡大投資する商品カテゴリ
- 収益改善が必要な商品カテゴリ
- 新規出店候補
- 次の90日の行動

時間が押した場合は、配布ブックの「役員会サマリー」シートをCXO-12の出発点として使用します。

## REFLECT（約30秒、またはCXO-12後に実施）

- 売上だけを見た判断と、利益・市場情報まで加えた判断に違いはあったか
- バブルチャートによって、投資先を議論しやすくなったか
- 役員会でそのまま使える「判断と根拠」になっているか

## 進行上の省略ルール

10分を優先する場合、次は行いません。
- 分析観点ごとの個別プロンプト
- 商品カテゴリの5段階採点
- 詳細な出店評価軸の読み上げ
- チャートの追加装飾
- 全数値の検算

ただし、**経営課題3点、商品投資判断、バブルチャート、出店候補3件、役員会向けサマリー**は残します。

## 注意

Copilotが生成した数値、分析、チャート、出典は確認してください。確認できない情報を推測で補わないでください。出店や投資の最終判断には、財務、市場調査、店舗開発などの専門家への確認が必要です。
