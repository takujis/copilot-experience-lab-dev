# CXO Experience ／ 中小企業経営層向け Copilot 体験

> このファイルは**ポインタ + 順番 + ルール**だけを持ちます。体験の中身は `contents/` にあります。

- **対象**：中小企業の経営層（社長、役員、部門責任者）、および本ワークショップを実施するパートナー
- **所要**：フルコース 約 120 分 ／ ショートコース 約 60 分
- **ゴール**：機能を知って帰るのではなく、**自社での着手 1 件と、動くエージェント 1 体を決めて帰る**
- **位置づけ**：製品デモでも研修でもなく、**経営判断の場**
- **演出**：コース料理（皿を順に出す）。ポイントやバッジは使いません

---

## この プログラムの考え方

経営層が Copilot に期待するのは「作業が速くなる」ことではありません。**判断が速くなる**ことです。

そのため本プログラムは、機能単位ではなく**経営者の一日の仕事の順**に並べています。
現在地を掴む → 危険を察知する → 数字を読む → **決める・作る・伝える** → 線を引く → 投資を決める。

体験の順番そのものが、経営会議の議事次第になっています。

### 3 つの原則

1. **自社のデータを使う。** 架空企業の事例は「自社データが出せない場合の逃げ道」です。経営層は他社の話に興味を持ちません
2. **各皿の最後に、必ずビジネス価値を着地させる。** 出力を眺めて次に進まないでください
3. **AI を疑う作法を持ち帰ってもらう。** 各体験に「Copilot 自身に反論させる」手順を入れています。ここを飛ばさないでください

**到達目標**：「Copilot は自分の仕事を把握している」を実感する

### スープ｜取引先の危険信号（15 分）

1. [主要取引先の危険信号を先に見つける](../../contents/08-personas/CXO-02_主要取引先の危険信号を先に見つける.md)

**必須**：1 つ
**到達目標**：「これは使える」と経営者が身を乗り出す

> **本プログラムで最も反応が大きい皿です。** 競合分析より、「あの取引先、最近様子がおかしい」のほうが経営者には切実です。
> **注意**：実在の取引先名が画面に出ます。複数社が同席する場では、画面共有を止めるか社名を伏せて進めてください。

### メイン｜決める・作る・伝える（35 分）

1. [幹部との1on1と経営会議を10分で仕込む](../../contents/08-personas/CXO-05_幹部との1on1と経営会議を10分で仕込む.md)（15 分）
2. [月次報告のスライドをその場で作らせる](../../contents/08-personas/CXO-07_月次報告のスライドをその場で作らせる.md)（20 分）
3. [決めたことを伝わる言葉にする](../../contents/08-personas/CXO-06_決めたことを伝わる言葉にする.md)（時間があれば）

**必須**：CXO-05 と CXO-07 ／ **選択**：CXO-06
**到達目標**：**経営者の一日そのもの**を一気通貫で通す

> [!IMPORTANT]
> **ここが本プログラムの山場です。** 「議題を作る／資料にする／伝える」は、経営者が最も時間を奪われ、かつ最も人に任せづらい 3 点セットです。
> 特に **CXO-07 は必ず通してください。** 月次報告に毎月半日かけている経営者にとって、1 枚が数分で出る体験は決定打になります。
> この皿だけで 35 分を確保し、他を削ってでも守ってください。

### 口直し｜安心の線引き（10 分）

1. [情報の線引きを経営者が決める](../../contents/08-personas/CXO-08_情報の線引きを経営者が決める.md)

**必須**：1 つ
**到達目標**：「で、情報は大丈夫なのか」に、経営者自身が答えを出す

> **この皿を省かないでください。** 中小企業で導入が止まる理由の第一位はここです。
> デザートの前に置くことで、「使わせてよいのか」の判断が済んだ状態で展開の議論に入れます。
> 最終判断は顧問弁護士等の専門家に確認する前提であることを、必ず口頭でも伝えてください。

---

### デザート｜自社への持ち帰り（20 分）

1. [AIをどこに効かせるか対話で見つける](../../contents/08-personas/CXO-09_AIをどこに効かせるか対話で見つける.md)
2. [自社の最初の1体を作る](../../contents/08-personas/CXO-10_自社の最初の1体を作る.md)

**必須**：CXO-09 ／ **推奨**：CXO-10（Agent Builder が使えない場合はデモ視聴）
**到達目標**：**その場で着手 1 件を確定させる**

> CXO-09 では Copilot が参加者に質問します。**答えるのは参加者です。** ここが本プログラムでいちばん頭を使う時間なので、進行役は口を挟まず待ってください。

---

### コーヒー｜次の一歩（5 分）

参加者に、次の 3 つを声に出して確認してもらいます。

1. 今日いちばん自社に効きそうだった体験はどれか
2. [CXO-09](../../contents/08-personas/CXO-09_AIをどこに効かせるか対話で見つける.md) で決めた着手 1 件は何か
3. 30 日後に「うまくいった」と言うための判定基準は何か

継続する場合は [Copilot in 30](../copilot-in-30/README.md) に接続します。

## 実施形式

事前に**どちらで行うかを決めてから**当日を迎えてください。

| モデル | 適する相手 | 進め方 |
|---|---|---|
| ハンズオン形式 | Microsoft 365 Copilot ライセンスがあり、自分のメール・会議・ファイルにアクセスできる少人数（1〜5 名） | 経営者本人が自分のデータで実施 |
| 進行役によるデモ形式 | ライセンス未導入、試用開始前、複数社が同席、時間が限られている | 進行役が実演し、参加者は自社への適用を議論 |

> **単独開催を強く推奨します。** CXO-02 と CXO-05 は実在の取引先・人物を扱うため、複数社が同席する場ではハンズオンにできません。

## 事前準備チェックリスト

- [ ] 実施形式（ハンズオン／デモ）を決定した
- [ ] コース（フル 120 分／ショート 60 分）を決定した
- [ ] ライセンスとアクセス（Copilot Chat / M365 Copilot / Researcher / Analyst / Agent Builder / Cowork）を確認した
- [ ] 参加者に「自分の実データを使う」ことを事前案内した
- [ ] 参加者の会社のホームページ URL を確認した（アミューズで使用）
- [ ] 参加者が月次で作っている報告資料の形式を聞いておいた（CXO-07 で使用）
- [ ] Agent Builder の作成・共有可否を管理者に確認した（CXO-10 で使用）
- [ ] 利用できない場合に備えた代替資料（事前に取得した出力例）を用意した
- [ ] 画面共有時に社名・個人名が映ってよいかを確認した

### データが用意できない場合

自社データを使いにくい体験は、サンプルで代替できます。

- レイクショア サンプルデータ一式（`contents/assets/lakeshore-sample-data-ja/`）
- Copilot Executive Workshop 同梱データ（`Store Data.xlsx`、`AI-PROJ-001`〜`005` など）

ただし、**サンプルは逃げ道です。** 主役は参加企業自身のデータであることを忘れないでください。

## ファシリテーター向けの心得

- **ビジネス ファーストで進める。** 技術ラボとして位置づけない
- **ライセンスと機能の説明に時間を使わない。** 聞かれたら答える程度にとどめる
- **出力が人によって異なるのは当たり前**であることを、最初に伝えておく
- **各皿の最後に、必ずビジネス価値を着地させる**（「で、これは御社の何が変わりますか？」と毎回聞く）
- **「反論させる」手順を飛ばさない。** ここを省くと、経営者は AI を過信するか、逆に一度の誤りで見限ります
- 当日のトラブル対応に時間をかけすぎない。詰まったら迷わずデモに切り替える
- **手ぶらで帰さない。** 着手 1 件と判定基準は、必ず紙かメモに書いて持ち帰ってもらう

## トラブルシューティング

| 症状 | 対応 |
|---|---|
| サインインできない | 正しい職場アカウントか確認 → 再読み込み → プライベート ウィンドウで試す |
| 個人アカウントでサインインしている | サインアウトし、タブを閉じ、職場アカウントで開き直す |
| Copilot が自分のデータを参照しない | **Work** が選択されているかを確認する |
| 引用元が表示されない | ファイルが OneDrive / SharePoint にあることを確認する。それでも出ない場合はデモに切り替える |
| Researcher / Analyst が見当たらない | **すべてのエージェント／エージェントの取得／エージェントを参照**（表示名は環境により異なる）から検索する |
| Excel の Copilot が分析できない | ブックが OneDrive / SharePoint に保存され、データがテーブル形式になっているか確認する |
| PowerPoint に Copilot が出ない | PowerPoint 向けのアクセスがない、または組織で有効化されていない可能性がある。CXO-07 はデモに切り替える |
| Agent Builder が使えない | CXO-10 はデモ視聴に切り替え、インストラクションの書き方だけ持ち帰ってもらう |
| 実データを画面に出せない | サンプルデータに切り替えるか、参加者の手元だけで実施し、画面共有は進行役の環境で行う |
| 時間が押している | 魚料理（CXO-04）→ 口直し（CXO-08）の順で削る。**メインとデザートは削らない** |
