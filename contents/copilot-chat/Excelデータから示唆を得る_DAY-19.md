# Excelデータから示唆を得る｜DAY-19

| 項目 | 内容 |
|---|---|
| **目的** | 集計作業ではなく、意思決定に使える示唆を取り出す |
| **所要** | 約 15 分（目安） |
| **利用** | Excel の Copilot ／ Microsoft 365 Copilot Chat（Work） |
| **入力** | OneDrive または SharePoint 上の、自分がアクセスできる Excel ファイル |
| **成果** | 列の説明、傾向・増減・外れ値、意思決定に使える示唆、追加で必要なデータ |
> **実施条件**：Excel ファイルは OneDrive に保存し、AutoSave を有効にする必要があります。
> Copilot in Excel の利用条件や表示される機能は、ライセンスとテナント設定によって異なる場合があります。ハンズオンが難しい場合は、ファシリテーターのデモを見ながら進めてください。

---

## シナリオ

サンプルの売上データではなく、**参加者がアクセス可能な実際の Excel** を使います。

いきなり分析させず、まず「列と内容の説明」から始めさせるのがポイントです。データの理解が違っていれば、そのあとの示唆もすべて外れます。

> 進行役の説明例：「最初に列の説明をさせてください。そこが合っていなければ、示唆は読まなくて構いません。」

---

## TRY — 手順

1. 対象の Excel ファイルを OneDrive または SharePoint 上で開く
2. AutoSave が有効になっていることを確認する
3. データ範囲がテーブル形式（見出し行あり）になっていることを確認する
4. Copilot を起動する
5. 次のプロンプトを貼り付ける

```text
このデータについて、まずデータの列と内容を説明してください。
その後、次を確認してください。

- 主要な傾向
- 目立つ増減
- 外れ値
- 比較すべき項目
- 意思決定に使えそうな示唆
- 追加で確認すべきデータ

計算根拠を示し、データに存在しない値は推測しないでください。
```

6. **送信**を選ぶ
7. 列の説明が実際のデータ定義と合っているかを確認する
8. 示された数値を、自分で 1 つ検算する
9. 外れ値が本当に異常値かを確認する
10. 「追加で確認すべきデータ」を、次の分析依頼に反映する
