# 自社紹介を視覚化する｜DAY-18

| 項目 | 内容 |
|---|---|
| **目的** | 文章の塊を、一目で全体像が分かるビジュアル案に変える |
| **所要** | 約 15 分（目安） |
| **利用** | Microsoft 365 Copilot Chat（Work） ／ PowerPoint の Copilot |
| **入力** | 自社の会社紹介資料、または公開 Web ページ |
| **成果** | 新入社員・学生向けの会社紹介インフォグラフィック案 |

> **実施条件**：Microsoft 365 Copilot のライセンスがあり、自分のメール・会議・ファイルにアクセスできる場合にハンズオンで実施します。
> そうでない場合は、ファシリテーターのデモを見ながら進めてください。

---

## シナリオ

ここは 30 日プログラムの**中盤の山場**です。「視覚的に、おっ！と思う体験」を意図的にこの位置に置いています。

自社の紹介資料または公開 Web ページを素材に、専門用語を減らし、一目で伝わる構成へ作り替えます。

> 進行役の説明例：「文章を短くするのではなく、見た瞬間に全体像が分かるかどうかで評価してください。」

---

## TRY — 手順

1. 自社の会社紹介資料、または公開 Web ページを用意する
2. Copilot Chat を開く
3. 対象の資料または URL を指定する
4. プロンプト ボックスをクリックする
5. 次のプロンプトを貼り付ける

```text
この会社紹介資料または公開Webページを基に、
新入社員または学生向けの会社紹介インフォグラフィック案を作ってください。

含める内容：
- 会社が解決している課題
- 主な事業
- 顧客への価値
- 強み
- 今後の方向性

専門用語を減らし、一目で全体像が分かる構成にしてください。
```

6. **送信**を選ぶ
7. 5 つの要素がすべて含まれているかを確認する
8. 専門用語が残っていないかを確認する
9. 事実と異なる説明がないかを、元資料と突き合わせる
10. PowerPoint でビジュアル化し、他の参加者に見せて反応を確かめる

> **体験ポイント**：「視覚的に、おっ！と思う体験」を中盤の山場に置く。
