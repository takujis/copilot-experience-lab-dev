# 分析結果を役員会資料に変える｜CXO-12

| 項目 | 内容 |
|---|---|
| **目的** | Excel で分析した商品・地域・出店の判断を、前年の役員会資料のスタイルを使って、承認を得るための PowerPoint へ変える |
| **所要** | 約 20 分（目安） |
| **利用** | Copilot in PowerPoint |
| **入力** | [`TrendStyleJapan-SalesData.xlsx`](../assets/CXO-11/TrendStyleJapan-SalesData.xlsx)（CXO-11 で分析したサンプル ブック）、[`TrendStyleJapan_2025年度_役員会資料テンプレート.pptx`](../assets/CXO-12/TrendStyleJapan_2025年度_役員会資料テンプレート.pptx)（架空企業の前年役員会資料） |
| **成果** | 商品投資・重点地域・出店検証の承認事項が分かる 2026 年度の役員会資料 1 式、スピーカーノート、想定質問と回答案 |

> **実施条件**：PowerPoint で Microsoft 365 Copilot が使える場合にハンズオンで実施します。
> Excel と PowerPoint は OneDrive または SharePoint に保存してください。
> そうでない場合は、ファシリテーターのデモを見ながら進めてください。画面や利用できる機能は環境によって異なる場合があります。

> **前提コンテンツについて**：この体験は [売上データと市場情報から成長戦略を決める｜CXO-11](./CXO-11_売上データと市場情報から成長戦略を決める.md) の続きです。CXO-11 を実施していない場合は、配布ブックの **「役員会サマリー」** シートをそのまま出発点として使ってください。

---

## シナリオ

あなたは、アパレルメーカー兼小売企業 **TrendStyle Japan**（架空の企業です）の経営企画部長です。

前の体験「売上データと市場情報から成長戦略を決める｜CXO-11」で、販売実績と市場情報を分析しました。拡大投資するカテゴリ、収益改善が必要なカテゴリ、重点地域、新規出店候補、次の 90 日まで整理できています。

社長から、こう言われています。

> 分析結果は分かった。来週の役員会で、何を承認すればよいか分かる資料にしてほしい。
> 去年の役員会資料のスタイルを使ってまとめてください。

この体験では、PowerPoint をゼロからデザインしません。**去年の役員会資料を開き、Excel で作った分析成果を参照して、今年の意思決定資料へ更新する**流れを体験します。

順番は 6 手です。① 前年資料のスタイルで初版を作る → ② 説明資料を意思決定資料へ変える → ③ 最重要スライドを判断できる 1 枚にする → ④ CEO と CFO の視点で点検する → ⑤ スピーカーノートを作る → ⑥ 想定質問に備える。

> 進行役の説明例：「Excel では『何が起きているか』を分析しました。PowerPoint では『何を決めてほしいか』に変えます。今日のゴールは、きれいなスライドではなく、**役員が承認・保留・追加調査を判断できる資料**です。」

---

## TRY — 手順

### 準備

1. [`TrendStyleJapan-SalesData.xlsx`](../assets/CXO-11/TrendStyleJapan-SalesData.xlsx) を OneDrive または SharePoint に保存する
2. ブックに **「役員会サマリー」** シートがあることを確認する（CXO-11 のステップ 8 で作成したサマリーです）
3. [`TrendStyleJapan_2025年度_役員会資料テンプレート.pptx`](../assets/CXO-12/TrendStyleJapan_2025年度_役員会資料テンプレート.pptx) を OneDrive または SharePoint に保存し、PowerPoint で開く
4. このファイルは **前年（2025 年度）の役員会資料** という設定です。次の 8 枚構成を確認する

   | スライド | 内容 |
   |---|---|
   | 2025 / ANNUAL BOARD REVIEW | 表紙 |
   | 01 / AGENDA | 本日の論点 |
   | 02 / EXECUTIVE SUMMARY | エグゼクティブ サマリー |
   | 03 / PERFORMANCE | 業績（売上成長と粗利率） |
   | 04 / PORTFOLIO | 商品ポートフォリオと投資選別 |
   | 05 / MARKET EXPANSION | 地域戦略と新規出店 |
   | 06 / 90-DAY ACTION | 次の 90 日の行動計画 |
   | DECISION REQUEST | クロージング（承認依頼） |

5. 前年資料を上書きしないよう、**別名で保存する**（例：`TrendStyleJapan_2026年度_役員会資料.pptx`）
6. Copilot アイコンを選び、Copilot ウィンドウが開くのを待つ

> この体験では Brand Kit は使用しません。**前年の PowerPoint を開始点**として、既存のテーマ、レイアウト、画像の使い方、情報量を引き継ぎます。

### ステップ 1 — Excel から今年の役員会資料を作る

7. Copilot から `TrendStyleJapan-SalesData.xlsx` を参照し、次のプロンプトを送信する

```text
添付のExcelを基に、前年資料のスタイルで2026年度の成長戦略を作成してください。
役員会向けに、商品投資・重点地域・出店候補の承認事項が分かる構成にしてください。
```

8. 生成前にアウトラインが表示された場合は、次の流れになっているかを確認する

   | 順 | セクション |
   |---|---|
   | 1 | エグゼクティブ サマリー |
   | 2 | 売上成長と収益課題 |
   | 3 | 商品ポートフォリオと投資判断 |
   | 4 | 地域戦略と新規出店候補 |
   | 5 | 承認事項と次の 90 日 |

9. 確認できたら、スライドを生成する
10. 生成された資料を開き、次の 4 点を確認する

    - 前年資料の色、フォント、余白、レイアウトが引き継がれているか
    - Excel の「役員会サマリー」「カテゴリ別集計」「地域別集計」「MarketData」が内容に反映されているか
    - 商品投資、重点地域、出店候補が資料に含まれているか
    - 元の Excel にない数値が追加されていないか

> ここが「おお！」となる瞬間です。**Excel の分析結果と前年の役員会資料を別々に開いて転記しなくても、今年の役員会資料の初版ができます。**

> **うまく動かない場合**：プレゼンテーション全体を一度に作れないことがあります。その場合は、別名保存した PowerPoint を開いたまま、Copilot で ［ファイルを参照］ または `/` から Excel を選び、次の短い指示でスライドを 1 枚ずつ追加してください。
>
> ```text
> このExcelから、商品投資の承認を求めるスライドを1枚追加してください。
> ```

### ステップ 2 — 説明資料を意思決定資料へ変える

11. 資料全体に対して、次のプロンプトを送信する

```text
説明資料ではなく意思決定資料にしてください。
各スライドの結論、承認事項、追加確認事項を明確にしてください。
```

12. 次の 4 点を確認する

    - 「売上推移」「地域別分析」のような、項目名だけのタイトルが減ったか
    - 「売上規模だけで投資しない」のように、タイトルだけで結論が分かるか
    - 役員が承認すること、保留すること、追加調査することが区別されているか
    - 最後に次の 90 日と判断ゲートがあるか

> **タイトルが結論になっているか**が、この体験でいちばん差の出る箇所です。読み上げなくても伝わるタイトルへ変わっているかを、全員で 1 枚だけ声に出して確認してください。

### ステップ 3 — 最も重要なスライドを判断できる 1 枚にする

13. 商品ポートフォリオのスライド（前年資料の `04 / PORTFOLIO` に相当）を選ぶ
14. 次のプロンプトを送信する

```text
このスライドを、成長率・粗利率・売上規模から投資判断できる1枚にしてください。
```

15. 次の 4 点を確認する

    - CXO-11 のバブルチャート（成長率 × 粗利率 × 売上規模）の考え方が引き継がれているか
    - 拡大投資、収益改善を条件に投資、維持、再設計の違いが分かるか
    - グラフや図の横に、役員への依頼が短く示されているか
    - 見栄えだけでなく、判断に使えるスライドになっているか

16. ［Visualize this slide］ が表示される環境では、文字量の多いスライドを選んで実行し、変化を比較する

### ステップ 4 — CEO と CFO の視点で点検する

17. 資料全体に対して、次のプロンプトを送信する

```text
CEOの視点で、成長機会と投資優先順位が伝わるように改善してください。
```

18. 続けて、次のプロンプトを送信する

```text
CFOの視点で、粗利・リスク・撤退条件の不足を指摘してください。
```

19. 次の 3 点を確認する

    - CEO の視点では、どこへ投資し、どの成長を狙うのかが明確か
    - CFO の視点では、収益性、リスク、追加確認データ、見直し条件が示されたか
    - CFO の指摘をすべて自動反映せず、役員会前に人が判断すべき論点として残せているか

> CFO のプロンプトは**指摘だけを求めています**。指摘のうち、どれを資料へ反映し、どれを論点として残すかは、参加者が決めてください。

### ステップ 5 — スピーカーノートを作る

20. 次のプロンプトを送信する

```text
各スライドに、役員会で45秒以内に説明できるスピーカーノートを追加してください。
```

21. 次の 4 点を確認する

    - 最初に結論を述べているか
    - グラフを読み上げるだけでなく、意思決定への意味を説明しているか
    - 次のスライドへのつながりがあるか
    - 元の Excel にない数値を作っていないか

### ステップ 6 — 役員会の質問に備える

22. 次のプロンプトを送信する

```text
CEO、CFO、営業担当役員から想定される質問と回答案を作成してください。
追加確認が必要な質問は分けてください。
```

23. ［Prepare for Questions］ が表示される環境では、このスキルも実行して結果を比較する
24. 次の 4 点を確認する

    - CEO、CFO、営業担当役員で質問の観点が異なるか
    - Excel や資料で回答できる質問と、追加確認が必要な質問が分かれているか
    - 回答案に根拠があるか
    - 推測を事実として回答していないか

### ステップ 7 — 役員会に出せるかを確認する

25. 最後に、次の 8 点を確認する

    - [ ] 前年資料のテーマとレイアウトを引き継いでいる
    - [ ] Excel で決めた商品投資、重点地域、出店候補が含まれている
    - [ ] 各スライドのタイトルが結論になっている
    - [ ] 承認事項と追加確認事項が分かれている
    - [ ] 元の Excel にない数値を作っていない
    - [ ] 次の 90 日と判断ゲートが示されている
    - [ ] スピーカーノートがある
    - [ ] 想定質問と追加調査項目が整理されている

26. 埋まらない項目があれば、**足りないのは数字か、根拠か、リスクの記述か**を言葉にする

## REFLECT — 振り返り

- Excel の分析結果から役員会資料の初版まで、どこまで自動化できたか
- 前年の PowerPoint を開始点にしたことで、デザイン調整はどれだけ減ったか
- 「説明する資料」から「承認を得る資料」へ、何が変わったか
- CEO と CFO では、同じ分析結果の見方がどう変わったか
- Copilot が作った内容のうち、人が判断・検算すべき部分はどこか

この体験で持ち帰ってほしいことは、次の一言です。

> **Copilot in Excel で「何をすべきか」を考え、Copilot in PowerPoint で「何を決めてほしいか」を伝えられる。**

**うまく動かない場合**
Excel と PowerPoint が OneDrive / SharePoint に保存され、Copilot からファイルを参照できることを確認してください。機能の表示やファイル参照が可能な形式は、環境によって異なる場合があります。

> [!CAUTION]
> Copilot が生成した数値、文章、グラフ、スピーカーノートは必ず確認してください。確認できない情報を推測で補わないでください。投資、出店、財務の最終判断には、財務、市場調査、店舗開発などの専門家への確認が必要です。
